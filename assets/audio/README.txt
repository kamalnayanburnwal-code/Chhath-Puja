BACKGROUND MUSIC
Download your music and rename it exactly:   background-music.mp3
then upload it into this folder (assets/audio/). That is all, no code changes.
(.m4a, .ogg or .wav with the same name also work.)

Use soft Indian instrumental music you have the right to use (bansuri / santoor).
Keep it under ~4 MB (128 kbps is plenty). It loops automatically.
Until the file exists the music button just shows a small "coming soon" message.
